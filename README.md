# Çok Satıcılı Pazar Yeri Web Sistemi (Marketplace System)

Bu proje, çok satıcılı bir e-ticaret pazar yeri platformu için tasarlanmış ilişkisel veritabanı mimarisini ve geliştirme aşamasındaki web uygulamasını içermektedir. Sistem; müşteri ve satıcı yönetiminden varyantlı ürün takibine, kategori bazlı komisyon hesaplamalarından kargo ve iade süreçlerine kadar uçtan uca bir pazar yeri işleyişini modellemektedir.

## Kullanılan Teknolojiler

* **Veritabanı Yönetim Sistemi:** MySQL (MAMP)
* **Veritabanı Araçları:** DBeaver
* **Backend (Geliştirme Aşamasında):** Python, Flask
* **Frontend (Planlanan):** HTML, CSS
